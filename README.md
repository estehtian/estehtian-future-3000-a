# CUPTEA by Esteh Tian Group — FUTURE 3000
Website statis dengan gaya futuristik neon teal/cyan, glass UI, grid background, animasi halus, dan desain responsif.

## File
- `index.html` — beranda dan katalog contoh
- `promo.html` — promo
- `galeri.html` — galeri
- `pemesanan.html` — formulir persiapan pesanan
- `cerita.html` — profil, visi, misi
- `lokasi.html` — lokasi dan kontak
- `faq.html` — FAQ
- `assets/style.css` — semua styling
- `assets/script.js` — navigasi mobile dan interaksi pesanan

## Pasang ke GitHub Pages
1. Ekstrak ZIP ini.
2. Buka repository `https://github.com/estehtian/estehtian-future-2050`.
3. Klik **Add file → Upload files**.
4. Unggah isi folder (jangan unggah ZIP saja). Pastikan `index.html` berada di root dan folder `assets/` berada di root.
5. Periksa konflik sebelum menimpa file yang sudah ada, lalu klik **Commit changes**.
6. Jangan ubah Settings → Pages atau DNS jika konfigurasi yang ada sudah berjalan.
7. Buka `https://estehtian.github.io/estehtian-future-2050/` setelah deployment selesai.

## Wajib disesuaikan
- Isi `WHATSAPP_NUMBER` pada `assets/script.js` dengan nomor resmi dalam format internasional tanpa tanda + atau spasi.
- Ganti placeholder alamat dan kontak di `lokasi.html`.
- Sesuaikan menu, harga, promo, dan gunakan foto produk asli jika ada. Foto pada template ini merupakan gambar referensi eksternal.
- Email dan media sosial resmi belum ditambahkan.

GitHub Pages hanya hosting statis. Template ini tidak mempunyai database, admin panel, backend, pembayaran online, atau penyimpanan pesanan.
